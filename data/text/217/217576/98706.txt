Proposed variables to track IN THE LOAD REALIZATION MODEL
Project owner;
Name of project; 
Project address; 
Project contact information (E-mail, phone-number, and points of contact);
Project location in Georgia Power’s service testimony (Y/N);
Announced Project Demand (MW);
Georgia Power estimate of Project Demand (MW, %);
Date of first notification of project/interest in service by Georgia Power;
All Project follow-up date(s) and reason for follow up, for example:  
Project updated announced load,
Project delayed start date, 
Date of notice,
Date of new project start,
Georgia Power provided offer letter to Project,
Project signs Request For Service,
Project modifies ramp up estimates,
Engineering estimates provided to Project,
Offer signed by Project,
Start of Georgia Power engineering work,
Completion of Georgia Power engineering work, and
Initial service date;
Date of Commitment to Georgia Power;
Date notified of Project loss, if applicable;
Project cancellation date, if applicable;
Reason for project loss (selected alternative state/selected alternative GA supplier/ Project cancelled/ project delayed indefinitely); and
Energy Consumption history (GWh, coincident peak, and non-coincident peaks by month, from start through 5 years of service).

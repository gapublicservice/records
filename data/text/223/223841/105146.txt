===== DKT 44280 STF-PIA-31/STF-PIA-31-14.docx =====
STF-PIA-31-14

Question: 

Provide a description of the error, including: 
How the 12-month lookback was implemented. 
How it differs from the expected "same-month-last-year" comparison.

Response:

For the Bill Comparison feature in the app, the front-end uses an application programming interface (“API”) to fetch billing history by specifying a start and end date. Initially, the start date was set to “current date - 13 months,” which caused the issue where only 11 bills were retrieved if the customer’s current month bill was not yet issued. For example, if in June 2025 the customer’s current month bill was not yet issued, the Bill Comparison screen would show July 2024 data as the bill from one year prior, instead of June 2024 data..

To fix the issue, the start date was changed to “current date - 14 months” to ensure at least a 12-month billing history is always retrieved. This ensures that a bill comparison always shows the bill from twelve months prior to the current month.
